# 🦉 Novel OS — Image Prompt Pack (Comic Style)

Every prompt below is **fully self-contained** — copy any single code block, paste into ChatGPT (or any image model), and generate. No placeholders to fill in, no other section to reference.

**One instruction for all prompts:** upload `assets/mascot.png` as a reference image in the same message. Add the sentence *"Use the owl character from this reference image — same face, same uniform, same proportions."* before the prompt body. That's the only thing that keeps the owl on-model across slides.

## 🛠️ Troubleshooting

| Problem | Fix |
|---|---|
| Owl looks different across slides | Always upload `assets/mascot.png` as a reference and prepend: *"Use the owl character from this reference image — same face, same uniform, same proportions."* |
| Result comes back photorealistic or 3D | Regenerate with: *"flat comic illustration only, no 3D, no photorealism, bold ink outlines required."* |
| Halftone is missing or too smooth | Add: *"increase halftone dot density, more visible Ben-Day pattern, comic print texture."* |
| Logotype mangled | Render the slide with empty logo space and overlay the wordmark from the mascot file in any image editor |
| Wrong aspect ratio | Restate the dimensions at both the start AND end of the prompt; some models honor only one |
